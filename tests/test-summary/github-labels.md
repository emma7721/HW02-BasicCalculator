# GitHub Labels đề xuất

Tạo các labels này trong repository để lọc và thống kê.

| Nhóm | Labels |
| --- | --- |
| Type | `type: test-case`, `type: test-run`, `type: bug`, `type: task` |
| Module | `module: calculator` |
| Technique | `technique: EP`, `technique: BVA` |
| Result/Status | `result: pass`, `result: fail`, `result: blocked`, `status: ready for retest` |
| Priority/Severity | `severity: critical`, `severity: major`, `priority: P0`, `priority: P1` |

Ví dụ filter GitHub Issues: `is:issue label:"type: bug" label:"status: ready for retest"`.
